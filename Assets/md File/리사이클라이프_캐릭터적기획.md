# 리사이클 라이프 — 캐릭터 & 적 기믹 기획서 (프로그래머 전달용)

> **문서 목적:** 개발(박성희) 구현 지시용. **확정 사항**은 그대로 구현하고, **미정 사항**은 회의 후 확정되는 대로 갱신한다.
> **전제:** 체력·공격력 수치는 3~5 수준의 낮은 정수로 간다. 재미는 수치 차이가 아니라
> **"연쇄 규칙에 개입하는 캐릭터 개성"**과 **"판을 복잡하게 만드는 적 기믹"**에서 나온다.
> **작성/관리:** 이진혁(팀장·기획) · **최종 수정일:** `[날짜]`

---

## ✅ 확정 사항

### 1. 플레이어 캐릭터 — 확정된 것

- 캐릭터는 **총 3종**.
- **캐릭터 A (기본형):** 공격력 **2**. 부딪힌 대상 1칸만 공격. 기준 캐릭터.
- **캐릭터 B (사이드 어택형):** 공격력은 **1** (A보다 한 방이 약한 대신, 여러 칸을 동시에 때린다).
  부딪힌 대상에 1데미지 + **그 대상의 양옆 칸에도 각 1씩** 동시 공격. 최대 3칸에 영향.
  - 양옆 칸에 적이 없으면 그냥 무시(공허 타격).
  - 인접 동종 연쇄 판정은 기존 로직과 동일하게, **각 피격 칸마다 독립적으로 발동**한다. (중앙 1 + 좌우 2 = 최대 3곳에서 각각 연쇄 시작)

**프로그래머 구현 방식 (확정):**
캐릭터별 공격 범위는 하드코딩하지 않고, **공격 패턴을 좌표 오프셋 리스트로 데이터화**해서 캐릭터 데이터(ScriptableObject 등)에 넣는다.
- A = `[(0,0)]` (부딪힌 칸만)
- B = `[(0,0), (-1,0), (1,0)]` (부딪힌 칸 + 좌우)
- 연쇄 판정 로직(Flood Fill)은 그대로 두고, "공격 시작점이 여러 개일 수 있다"로만 처리하면 됨. 이렇게 해두면 캐릭터가 늘어도 오프셋 리스트만 추가하면 됨.

### 2. 적 기믹 — 확정된 것

- **스턴형 (잡몹 기믹):** 플레이어가 이 적을 한 대 치면, 해당 적이 **다음 1턴(행동 1회)** 동안 반격/이동 등 행동을 못 한다. → 플레이어에게 "안전하게 처리할 타이밍"을 만들어줌.
- **보스 공통 기믹 — 광역 방해 공격:** 보스가 주기적으로 **큰 범위 공격**을 시전해 플레이어 동선을 강제로 제한하고, 그 동안은 플레이어가 딜 넣을 타이밍이 없어진다(딜타임 제거). 패턴을 피해다니다 빈틈에만 공격하는 구조를 유도.
- **보스 공격 원칙:** 반드시 **예고(텔레그래프) 후 발동**한다. 예고 없이 즉시 맞으면 "불합리한 죽음"으로 느껴지므로 금지.

**프로그래머 구현 방식 (확정):**
- 스턴 상태는 **범용 상태이상(디버프) 시스템**으로 구현한다 (이후 다른 상태이상이 추가될 걸 감안).
- 보스 패턴은 캐릭터 공격처럼 좌표 오프셋 + **시전 타이밍(예고 → 발동)** 구조로 짠다.

### 3. 몬스터 물량 — 확정된 것

| 구분 | 수량 |
|---|---|
| 잡몹 | 9종 |
| 벽(장애물) | 3종 |
| 보스 | 3종 (스테이지 강/산/바다당 1종) |

### 4. 설계 원칙 (확정 — 팀 공유용)

1. 체력·공격력 숫자로 차별화하지 않는다. 숫자는 낮게, 규칙 개입으로 재미를 만든다.
2. 캐릭터 개성 = "공격이 어디에, 어떻게 들어가는가"를 다르게 한다.
3. 적 기믹 = "플레이어의 다음 행동을 얼마나 흥미롭게 제약하는가"로 설계한다.
4. 보스 공격은 항상 예고 후 발동한다 (불합리한 피격 방지).
5. 확장을 고려해 공격 범위·패턴은 하드코딩이 아니라 데이터(좌표 오프셋)로 관리한다.

## ❓ 미정 사항 (회의 후 확정 필요)

### 1. 플레이어 캐릭터

| 항목 | 내용 |
|---|---|
| A·B 체력 수치 | 구체적 숫자 미정 (예: 3? 4?) |
| B의 "양옆" 기준 축 | 그리드 고정 좌/우인지, 이동 방향 기준으로 회전하는지 미정 |
| 캐릭터 C | 체력·공격력·기믹 전부 미정 |

### 2. 적 기믹

| 항목 | 내용 |
|---|---|
| 잡몹 추가 기믹 | 스턴형 외 추가 기믹(위장형·순간이동형·폭발형 등) 미정 |
| 벽 기믹 상세 | 공격 가능 여부, 파괴 시 효과 미정 |
| 보스 개별 패턴 | 공통 기믹(광역 방해) 외에 보스마다 가질 고유 패턴 1개씩 미정 |
