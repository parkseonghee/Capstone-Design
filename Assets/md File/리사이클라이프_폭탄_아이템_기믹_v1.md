## 1. 폭탄

### 1-1. ✅ 확정 사항

| 항목 | 값 |
|---|---|
| 폭발 범위 | **3 × 3** (폭탄 칸 중심) |
| 폭발 피해 | **5** |
| 기폭까지 | **3턴 뒤** |
| 낙하 | **O** — 다른 블록과 똑같이 중력을 받는다. 단 **놓은 턴만 제자리에 버틴다**(§1-2) |
| 보스에게 피해 | **O** — 단, 폭탄 수급량으로 조절이 필요하다 |
| 처치 시 골드 | **O** — 폭탄으로 죽인 몬스터도 돈을 떨어뜨린다 |
| 조작 | 폭탄 **설치키**가 별도로 필요하다 (방향키와 별개) |

> 피해 5는 현재 잡몹 체력대(1~4)를 전부 덮고, 벽 중 나무(3)·콘크리트(5)까지 한 번에 날린다.
> 철제(6)만 살아남는다. 이게 의도인지는 §1-2의 "벽에도 피해가 들어가는가"와 함께 확인할 것.

### 1-2. ✅ 설치와 기폭 (확정)

**설치**
1. **전용 버튼을 꾹 누르면** 플레이어로부터 **한 칸 거리**의 설치 가능 칸이 화면에 표시된다.
2. 표시되는 건 **빈 칸뿐**이다 — 몬스터·블록·벽이 있는 칸에는 못 놓는다.
3. 표시된 칸 중 원하는 곳을 골라 폭탄을 설치한다.
4. **놓은 폭탄은 그 턴에는 떨어지지 않는다.** 설치와 동시에 한 칸 내려가 버리면
   조준한 자리와 실제로 놓인 자리가 달라져, 표시를 보고 고른 의미가 없어진다.
   다음 행동부터는 다른 블록과 똑같이 턴당 한 칸 떨어진다.

**기폭**
5. 설치된 폭탄은 **가만히 있는다. 카운트다운이 바로 시작되지 않는다.**
6. **플레이어가 그 폭탄을 때리면** 그때부터 카운트다운(3턴)이 시작된다.
7. 3턴이 지나면 3×3 범위에 피해 5. 불이 붙어 있는 동안 남은 턴 수가 폭탄 위에 숫자로 뜬다.

> 즉 폭탄은 "놓는 턴"과 "불붙이는 턴"이 갈라져 있다.
> 놓아두고 상황을 만든 뒤 원하는 타이밍에 점화하는 게 설계 의도다.

### 1-3. ❓ 미확정 — 남은 것

| 항목 | 내용 | 현재 코드 |
|---|---|---|
| **플레이어 피해** | 유물에 "폭발 피해 면역"이 있다는 건 기본적으로 플레이어도 맞는다는 뜻으로 보인다 | **임시로 O** (`BombConfig.damagesPlayer` 체크박스) |
| **폭탄 연쇄 폭발** | 폭발 범위 안의 다른 폭탄도 즉시 터지는가 | **임시로 O** (`BombConfig.chainDetonates` 체크박스) |
| **벽에 피해** | 폭발이 벽도 부수는가. 부순다면 "우회 유도" 설계와 충돌할 수 있다 | 현재 부순다(범위 안 모든 블록) |
| **시작 보유 개수** | 몇 개로 시작하는가. 수급 경로(드롭? 상점?)도 미정 | `BombConfig.startingCount` 값 |
| **설치도 한 턴인가** | 놓는 것만으로 보드가 진행되는가(중력·스폰) | **O** — 보드는 진행되지만 방금 놓은 폭탄만 그 턴 중력을 건너뛴다(§1-2) |
| **이미 점화된 폭탄을 또 때리면** | 무시? 즉시 폭발? | 현재 무시 |

> 위 "임시" 항목은 전부 **인스펙터 값**이라 확정되면 체크박스만 바꾸면 된다(Hard Rule 1·11).

**연쇄 판정과의 관계 (확정)**: 폭발은 **범위 피해**라 같은 종류 연쇄를 일으키지 않는다.
반대로 캐릭터의 공격 범위(캐릭터 B의 양옆 등)에 폭탄이 걸리면 **그 폭탄도 점화된다** —
"공격 범위 안의 각 칸은 자기 성격대로 처리된다"는 기존 규칙 그대로다.

## 2. 유물 아이템 (패시브 · 런 지속)

> 밸런싱 v1 §0-2의 전제("유물로 공격력이 오르는 걸 상정한다")와 이어진다.

| # | 유물 | 효과 | 비고 |
|---|---|---|---|
| 1 | 최대 체력 증가 | 최대 체력 상승 | **"2개"의 의미 미확정** — 이런 유물이 2종인지, 최대 체력 +2인지 |
| 2 | 골드 획득량 증가 | 획득 골드 증가 | 증가폭 미정 |
| 3 | 부활 | 사망 시 부활 | 1회성인지, 부활 시 체력 얼마인지 미정 |
| 4 | 폭발 범위 증가 | 폭탄 폭발 **3×3 → 5×5** | 확정 |
| 5 | 포션 회복량 증가 | 포션 회복 **2 → 3** | 확정 |
| 6 | 블록 처치 시 확률 회복 | 확률로 체력 회복 | 확률·회복량 미정 |
| 7 | 폭탄 +5개 | 보유 폭탄 +5 | 확정 (즉시 지급인지 최대 보유량 증가인지 미정) |
| 8 | 폭발 피해 면역 | 폭발에 플레이어가 안 맞음 | §1-2의 "플레이어 피해"가 O여야 의미가 있다 |
| 9 | 산성 면역 | 산성 피해 무효 | **"산성" 기믹 자체가 아직 정의되지 않았다** |

**공통 미확정:** 획득 경로(보상? 상점?), 중복 획득 가능 여부, 등급 구분 여부.

## 3. 일회성 아이템 (즉시 사용 · 슬레이 더 스파이어의 포션 느낌)

| # | 아이템 | 효과 |
|---|---|---|
| 1 | 전체 타격 | 사용 시 **맵 전체에 1 피해** |
| 2 | 전체 소탕 | 사용 시 **맵 전체 일반 몬스터 5마리 처치** |

**미확정**
- 소지 한도(슬롯 수)와 사용 조작
- "일반 몬스터"의 정의 — 벽과 보스는 제외인지
- 5마리를 **어떤 기준으로** 고르는지 (가까운 순? 체력 낮은 순? 무작위?)
- 사용이 한 턴을 쓰는지

## 4. 기믹 — 독

### 4-1. ✅ 확정 사항

- 한 번 밟기만 해도 **처음 밟았을 때 1 피해**.
- 그 뒤 **움직이면 1 피해**.
- 따라서 밟고 빠져나오면 **총 2 피해**.

### 4-2. ❓ 미확정

| 항목 | 내용 |
|---|---|
| 독의 형태 | 바닥 타일인가, 블록인가, 아니면 적이 남기는 장판인가? |
| 지속 | 계속 서 있으면 매 턴 1씩인가, 최초 1 + 탈출 1로 끝인가? |
| 범위·생성 | 몇 칸에 어떻게 생기는가? 시간이 지나면 사라지는가? |
| 산성과의 관계 | 유물 9번의 "산성"이 독과 같은 것인가, 별개 기믹인가? |

## 5. 선행 시스템 (없으면 이 문서의 절반이 못 굴러간다)

현재 코드에 **아직 없는** 것들이다.

| 시스템 | 필요한 이유 | 현재 상태 |
|---|---|---|
| **골드** | 폭탄 처치 드롭, 골드 증가 유물 | 없음 |
| **플레이어 인벤토리** | 폭탄 개수, 일회성 아이템 슬롯 | 없음 |
| **유물(패시브) 시스템** | 유물 9종 전부 | 없음 — `Player.Attack`이 생성 시 고정이라 가변화가 선행돼야 한다 |
| **상태이상** | 독(그리고 기존 기획의 스턴형 잡몹) | 없음 |
| **보스** | 폭탄이 보스에게 들어가는지 | 없음 |
| **추가 입력 키** | 폭탄 설치, 일회성 아이템 사용 | 방향 4키만 있음 |

## 6. 구현 순서 제안

**폭탄만 먼저 (지금 가능)**
1. `Bomb` 블록 — 낙하 O, 3턴 카운트다운, 3×3 / 피해 5 폭발
2. 설치키 입력 + 보유 개수 (수급은 임시로 인스펙터 값)

**선행 시스템이 필요한 것**
3. 골드 — 폭탄 처치 드롭
4. 유물 — 4·5·7·8번은 폭탄/포션에 직접 붙으므로 폭탄 다음이 자연스럽다
5. 독 — 상태이상 시스템과 함께 (기존 기획의 스턴형 잡몹도 같이 해결된다)
6. 일회성 아이템 — 인벤토리·입력이 생긴 뒤
7. 보스 — 별도 큰 작업
