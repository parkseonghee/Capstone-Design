# 리사이클 라이프 — 아이템 · 조합 레시피 (팀 내부용)

> **문서 목적:** 개발(박성희) 구현 지시용. 아이템 목록과 조합 레시피의 기준 문서다.
> **주의:** 레시피는 **임시안**이며 플레이테스트 후 조정 전제다.
> **작성/관리:** 이진혁(팀장·기획) · **최종 수정일:** `[날짜]`

---

## 1. 조합 시스템 규칙

| 항목 | 내용 |
|---|---|
| 재료 획득 | 50마리 처치마다 랜덤 재료 1개 보장 + 적 처치 시 5% 확률 드랍 (한 런 약 42~45개) |
| 조합 조작 | 인벤토리에서 드래그앤드롭. 재료 순서는 무관하게 처리한다(정렬 후 비교) |
| 블라인드 조합 | 레시피 정보 없이 시도 가능. **실패 시 사용한 재료는 전부 소멸** |
| 재료 가공 | 기초 재료 2개를 합치면 가공 재료가 된다. 같은 재료끼리는 **승급**, 다른 재료끼리는 **혼합** |
| 가공 재료 | 드랍되지 않고 조합으로만 획득. 가공은 1단계까지만(가공 재료끼리는 다시 합치지 않는다) |
| 인벤토리 | 12칸. 재료를 분쇄해 마을 재화로 전환하는 버튼 제공 |
| 획득 경로 | 유물은 조합 전용 / 폭탄·소모품은 조합과 상점 구매 둘 다 가능 |
| 상점 | 웨이브 사이 등장. 재료 위주 판매에 소모품·폭탄 일부. 리롤 버튼 제공 |

### 티어별 필요 재료 수

| 티어 | 대상 | 슬롯 | 기초 환산 |
|---|---|---|---|
| **T1** | 유물 1단계 | 3개 | 3 |
| **T2** | 유물 2단계 | 4개 | 5 |
| **T3** | 유물 3단계 | 5개 | 7 |
| **C1** | 소모품 1단계 | 2개 | 2~3 |
| **C2** | 소모품 2단계 | 3개 | 4 |
| **C3** | 소모품 3단계 | 4개 | 6 |

> **기초 환산** = 가공 재료를 기초 재료로 되돌렸을 때의 실제 소요량(가공 재료 1개 = 기초 2개).
> 소모품은 1회용이므로 유물보다 소요량을 낮게 둔다.

## 2. 재료 (총 16종)

### 2-1. 기초 재료 5종 — 몹 처치 시 드랍

| No | 명칭 | 출처 몹 | 테마 |
|---|---|---|---|
| M01 | **고철** | 캔 계열 | 공격 · 폭발 |
| M02 | **펠릿** | 페트병 · 플라스틱 | 방어 · 장비 |
| M03 | **펄프** | 종이 · 박스 | 포션 · 회복 |
| M04 | **필름** | 비닐봉지 · 과자봉지 | 차단 · 면역 |
| M05 | **잔재** | 일반쓰레기(컵라면 등) | 오염 · 고위력 |

### 2-2. 승급 재료 5종 — 같은 재료 2개

| No | 명칭 | 레시피 | 테마 |
|---|---|---|---|
| U01 | **고철+** | 고철 ×2 | 공격 강화 |
| U02 | **펠릿+** | 펠릿 ×2 | 방어 강화 |
| U03 | **펄프+** | 펄프 ×2 | 회복 강화 |
| U04 | **필름+** | 필름 ×2 | 면역 강화 |
| U05 | **잔재+** | 잔재 ×2 | 고위력 강화 |

### 2-3. 혼합 재료 6종 — 다른 재료 2개

| No | 명칭 | 레시피 | 테마 |
|---|---|---|---|
| X01 | **코팅 강판** | 고철 + 필름 | 공격 · 관통 |
| X02 | **슬래그** | 고철 + 잔재 | 폭발 · 고위력 |
| X03 | **합성 종이** | 펠릿 + 펄프 | 유틸 · 탐색 |
| X04 | **방수 시트** | 펠릿 + 필름 | 방어 · 면역 |
| X05 | **퇴비** | 펄프 + 잔재 | 회복 · 생명 |
| X06 | **고형 연료** | 필름 + 잔재 | 연소 · 광역 |

> 기초 재료 2개 조합은 총 15가지다. 그중 5가지는 승급, 6가지는 혼합 재료가 되고,
> **남은 4가지(고철+펠릿 / 고철+펄프 / 펄프+필름 / 펠릿+잔재)는 C1 소모품 레시피로 배정**했다.
> 15가지를 전부 재료 생산에 쓰면 2슬롯짜리 아이템을 만들 조합이 하나도 남지 않기 때문이다.

## 6. 미정 항목

- 상점 진열 방식 — 랜덤 진열 + 리롤 / 고정 진열 중 미정
- 재료 가격 · 리롤 비용(고정/증가) · 상점 슬롯 수
- 재료를 마을 재화로 바꾸는 분쇄 환율
- R11 재활용 장갑의 기준 마릿수와 회복량, C06 방독면의 지속 턴 수
- 조합 실패 시 재료 전액 소멸이 과한지 — 절반 반환 또는 '실패 조합 도감 기록' 검토
- 비워둔 4개 조합(고철+펠릿 등)을 추후 혼합 재료로 돌릴지 여부

## 7. 레시피 설계 메모

- 재료마다 테마를 부여했다 — 고철=공격·폭발 / 펠릿=방어·장비 / 펄프=포션·회복 / 필름=차단·면역 / 잔재=오염·고위력. 효과와 재료가 맞물려야 플레이어가 레시피를 추론할 수 있다.
- T1 유물은 기초 재료만 사용한다. 블라인드 조합으로 찾아내는 구간이기 때문이다.
- T2 이상은 가공 재료를 포함해 기초 환산 소요량을 크게 올렸다.
- 혼합 재료는 두 재료의 테마가 합쳐진 성격을 갖는다. 예) 고철(공격) + 잔재(고위력) = 슬래그 → 폭탄 계열에 들어간다.
- T2 이상은 블라인드 발견에 15판 이상 걸리므로, 마을의 랜덤 조합법 구매가 사실상 주 획득 경로다.
