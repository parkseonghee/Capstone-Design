# 리사이클 라이프 — UI 명세서 (팀 내부용)

> **문서 목적:** 개발자 화면 구현 지시용. 이 명세 기준으로 화면을 배치한다.
> **기준 해상도:** 1080 × 2340 (세로 고정)
> **작성/관리:** 이진혁(팀장·기획) · **최종 수정일:** `[날짜]`

---

## 1. 시작화면 (Title)

**역할:** 게임 첫 진입 화면. 로고 노출 후 화면 터치로 시작 (Touch to Start).

### 레이아웃 (1080 × 2340, 세로)
```
┌─────────────────────────┐  ← 상단 세이프에어리어 (~100px)
│                  [⚙ 설정] │  우상단
│                         │
│                         │
│                         │
│        [게임 로고]       │  중앙 (화면 높이 35~50%)
│                         │
│                         │
│                         │
│                         │
│     ✦ TOUCH TO START ✦   │  하단부 (높이 78% 부근), 깜빡임 연출
│                         │
│        ver 0.1          │  하단 중앙
└─────────────────────────┘  ← 하단 세이프에어리어 (~60px)
```

### UI 요소

| 요소 | 위치 | 크기(대략) | 동작 |
|---|---|---|---|
| 배경 | 전체 | 1080×2340 | 자연 테마 정지 이미지 (강/자연) |
| 게임 로고 | 중앙 | 폭 720px 내외 | - |
| "TOUCH TO START" 텍스트 | 하단부 | - | 깜빡임(페이드 인/아웃) 반복 연출 |
| 설정 아이콘 | 우상단 | 120×120 | 탭 → 설정 팝업(사운드·언어 등) |
| 버전 텍스트 | 하단 중앙 | - | 빌드 버전 표기 |

### 입력 / 화면 전환
- **화면 아무 곳이나 탭** → **마을**로 이동
- 단, **설정 아이콘 영역 탭**은 시작으로 넘어가지 않고 설정 팝업만 연다 (전체 터치 영역보다 설정 버튼 우선 판정)

### 비고
- 전체 화면이 터치 시작 영역이지만, 우상단 설정 버튼만 예외 처리해야 함 (개발 시 입력 우선순위 주의).
- "TOUCH TO START"는 깜빡임 연출로 "지금 탭하면 된다"를 직관적으로 알림.
- 텍스트·로고 모두 세이프에어리어 안쪽에 배치.
- 크기·위치 수치는 대략값이며, 아트·해상도 확정 후 조정한다.
